## 📖 About

This repository is a collection of practical tasks I work through while learning Docker and containerization. Each task is self-contained in its own folder, so you can explore them in any order. New tasks are added regularly. 🚧

## 🧰 Prerequisites

- 🐳 [Docker](https://docs.docker.com/get-docker/) installed
- 🧩 [Docker Compose](https://docs.docker.com/compose/install/) (included with Docker Desktop)
- 🔧 [Git](https://git-scm.com/downloads)
- 🐧 A Linux, macOS, or Windows (WSL2) environment


## 🚀 Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/adhamgamal22/<https://github.com/adhamgamal22/docker-devops-labs.git>.git

# 2. Move into the repository
cd <repo-name>

# 3. Open any task folder and follow its instructions
cd <task-folder>
```

## 💡 Tips

- 🧹 Clean up after each task to free resources:
  ```bash
  docker system prune
  ```
- 🔍 Use `docker ps -a` and `docker logs <container>` when something doesn't work.
- 📄 Check the files inside each task folder for task-specific steps.
